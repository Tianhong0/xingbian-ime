# xingbian.bin 二进制词典格式规范 v1

本文件是**唯一契约**。Python 写入端（`tools/build_dict.py`）与 C# 读取端
（`src/Xingbian.Core/DictFile.cs`）必须严格按此实现。

- 文件：`assets/build/xingbian.bin`
- 字节序：**全部小端 (little-endian)**
- 字符串编码：块 1 用 **UTF-8**；其余块内的字符一律 **UTF-16LE**
- 对齐：**不做任何对齐填充**

---

## 1. 文件头（**固定 32 字节**）

| 偏移 | 类型 | 名称 | 值 |
|---|---|---|---|
| 0  | char[4] | magic    | ASCII `XBIM` |
| 4  | u32     | version  | `1` |
| 8  | u32     | blockCount | 块数量 |
| 12 | u32     | reserved | `0` |
| 16 | byte[16] | reserved2 | 全 `0` |

> ⚠️ **头长度歧义已裁定（2026-10-16）**：上表只描述到偏移 12，但头长度**以 32 字节为准**。
> 字节 `16..31` 必须写 `0`，读取端**不做校验**（前向兼容）。因此：
> - 块目录起始偏移 = **32**
> - 第一个块的数据起始偏移 = **32 + 24 × blockCount**
>
> 写入端与读取端都必须按此实现；这是唯一的权威解释。

## 2. 块目录（每项 24 字节，紧跟文件头）

| 偏移 | 类型 | 名称 |
|---|---|---|
| 0  | u32 | blockId |
| 4  | u32 | reserved（0） |
| 8  | u64 | offset（自文件起始的绝对字节偏移） |
| 16 | u64 | length（字节长度） |

块目录后即数据区。块在文件中的物理顺序**不要求**与 blockId 顺序一致，
读取端必须依据目录定位。块区之外允许有填充字节。

## 3. blockId = 1 ：音节表 (Syllables)

UTF-8 文本。每行一个**无调拼音音节**（小写 ASCII，只含 `a-z`）。
行分隔符 `\n`（LF），最后一行**不带**结尾换行符。
行号（从 0 开始）即为**音节 ID**。
必须按**字节序升序**排序，且**无重复**。

示例内容：

```
a
ai
an
ang
ao
ba
...
```

## 4. blockId = 2 ：词表 (Words)

```
u32 count
重复 count 次：
    u16   wordLen     // 词的 UTF-16 码元数（= 汉字个数，BMP 内）
    u16   sylLen      // 该词的音节数
    u32   freq        // 词频（越大越常用，>=1）
    u16   sylIds[sylLen]   // 音节 ID 序列，按发音顺序
    char16 word[wordLen]   // 词本身，UTF-16LE
```

约束：
- `wordLen >= 1`，`sylLen >= 1`
- `sylIds` 中每个值必须 `< 音节表行数`
- 同一个词可出现多次（不同读音），读取端需合并

排序：**不做要求**。

## 5. blockId = 3 ：IDS 拆解表 (Ids)

```
u32 count
重复 count 次：
    u32    codepoint   // 该字的 Unicode 码点（不是 UTF-16 码元）
    u16    compLen     // 拆解结果的 UTF-16 码元数，0 表示不可拆
    char16 comps[compLen]  // 一级拆解出的部件，按书写顺序拼接
```

- 必须按 `codepoint` **升序**排序，**无重复**
- `compLen == 0` 的条目允许存在（表示显式标记为不可拆），读取端视同不存在
- 部件本身**已剥离** IDS 结构符（U+2FF0..U+2FFB），即 `你 = ⿰亻尔` → `comps = "亻尔"`

## 6. blockId = 4 ：元信息 (Meta)

UTF-8 JSON，内容自由（数据来源、生成时间、条数统计）。读取端可忽略。

| 数据 | 条数 |
|---|---|
| ids.txt 条目 | 88 937 |
| 其中可做一级拆解 | 88 480 |

---

## 8. 自检要求

`tools/build_dict.py` 必须提供 `--selftest`，至少校验：

1. magic / version / 目录 offset 正确，各块长度与目录一致
2. `你` → `亻尔`，`妈` → `女马`，`好` → `女子`，`测` → `氵则`
3. `ni ma` 能在词表中查到 `你妈`
4. 音节表有序无重复；IDS 表按码点有序无重复
5. 逐条回读 count 与写入值一致，且读到文件末尾时字节位置与目录 length 完全吻合
